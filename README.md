# 4U-Project 🤖

Página interativa em formato de chat, feita com HTML, CSS e JavaScript puros. Um pequeno projeto pessoal, feito com carinho para alguém muito especial.

## 📖 Sobre o projeto

A ideia começou em Python e depois foi reescrita em HTML/JavaScript, com ajuda de IA (Claude), pra rodar direto no navegador.

O robô **4U** conversa com quem abrir a página: pergunta o nome, faz algumas perguntas com botões de resposta e segue um roteiro até o final.

🔒 Tudo roda no navegador. Nenhum dado digitado é enviado ou salvo.

## 🛠️ Tecnologias usadas

- HTML
- CSS
- JavaScript (sem bibliotecas)
- GitHub Pages (publicação)
- Google Fonts

## ▶️ Como abrir na sua máquina

1. Baixe os arquivos do repositório (**Code → Download ZIP**) e extraia.
2. Abra o arquivo `index.html` no navegador.

> Precisa de internet pra carregar as fontes e o vídeo incorporado.

## 📁 Arquivos

- `index.html`: a página inteira (estilo e lógica incluídos)
- `Eu_sabo.jpg`: imagem usada na conversa (precisa ficar na mesma pasta do `index.html`)
